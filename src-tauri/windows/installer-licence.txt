WHAT LEAVES THIS PC

Cablebag sends nothing about you to its makers: there are no accounts, no statistics and no tracking.

- Updates: Cablebag asks GitHub whether a newer version is out. Turn this off in Settings, About Cablebag.
- Your sessions connect to the servers and sites you choose.
- The assistant, Sync and credential sources only talk to the host you set up yourself, and only once you do.
- Report a problem opens GitHub in your web browser, where you read it over and send it yourself.

More: https://github.com/maferick/cablebag#privacy
